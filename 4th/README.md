This is my fourth lesson of backend development.

# What I Learned.
- Introduction to Nodemon and how to run and stop it in the terminal.
- How to restart the Node.js server after stopping Nodemon.
- Introduction to the HTTP module in Node.js.
- How to use the HTTP module to work with server-related functionality.
- Introduction to JavaScript Modules.
- How to create a separate JavaScript file named `myModule.js`.
- How to export variables and values from one JavaScript file using `export`.
- How to import exported values into another JavaScript file using `import`.
- How to connect `myModule.js` with `script.js`.
- How to use `console.log()` to display imported values in the terminal.
- How to export multiple variables from a single JavaScript file.
- How to install multiple packages together using a single npm command.
- Understanding how npm manages dependencies inside the `node_modules` folder.
- How to organize JavaScript code into separate and reusable modules.
